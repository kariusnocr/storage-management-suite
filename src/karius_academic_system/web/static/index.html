Kho Dữ Liệu (Multi-Vault)

Quản lý mọi thư mục cục bộ trên máy tính, ổ cứng rời, NAS hoặc bất kỳ thư mục Google Drive nào.

Chào mừng đến với Karius Academic System (KAS)

KAS quản lý thống nhất mọi kho tri thức — từ thư mục cục bộ (E:\SÁCH, OneDrive, ổ rời) đến mọi thư mục Google Drive. Hãy kết nối kho đầu tiên của bạn bên dưới!

Kết nối Kho Dữ Liệu Mới
Hệ Sinh Thái Android & Ghép Nối Di Động (KAS Mobile · kas-android.apk)
Chạy độc lập 100% trên điện thoại/máy tính bảng Android, ghép nối Wi-Fi/LAN hoặc cài trên Termux.
Đang kiểm tra...
1. Ứng dụng Android Gốc (kas-android.apk)
Tích hợp sẵn máy chủ Python 3.11 + SQLite trên điện thoại Android (Android 8.0+) — duyệt kho ngoại tuyến, kết nối Google Drive OAuth 2.0 hoặc chuyển sang máy chủ PC qua Wi-Fi.
2. Ghép nối Wi-Fi / LAN & Android Termux
Địa chỉ LAN để mở từ ứng dụng KAS Android hoặc Chrome Android (cùng Wi-Fi):
http://127.0.0.1:8765
Hoặc cài trọn bộ CLI + OCR Tiếng Việt trên Android Termux (1 lệnh):
curl -fsSL https://raw.githubusercontent.com/kariusnocr/storage-management-suite/main/packaging/android/install_android_termux.sh | bash

                Chưa đăng nhập
              

              
Đang kiểm tra...


              

                
                
                
              

              

                
                
                
              

              

              

                Hướng dẫn lấy credentials.json miễn phí (4 bước)
                
    
                  
  1. Mở Google Cloud Console → Tạo dự án mới → vào APIs & Services → Library → bật Google Drive API.
    2. 
                  
  2. Vào OAuth consent screen → chọn External → thêm Gmail của bạn vào danh sách Test users.
    3. 
                  
  3. Vào Credentials → Create Credentials → OAuth client ID → chọn Desktop app → tải tệp JSON.
    4. 
                  
  4. Chọn tệp JSON ở ô trên → bấm Lưu credentials.json → bấm Đăng nhập Google Drive.
    5.
