    2. 
              
  2. Vào OAuth consent screen → chọn External → thêm Gmail của bạn vào danh sách Test users.
    3. 
              
  3. Vào Credentials → Create Credentials → OAuth client ID → chọn Desktop app → tải tệp JSON.
    4. 
              
  4. Chọn tệp JSON ở ô trên → bấm Lưu credentials.json → bấm Đăng nhập Google Drive.
